Component: EditSystemDatabase

The EditSystemDatabase React component provides a simple user interface for System Administrators to inspect database tables, select specific records, view current record values, and submit record edits to the system database.

Coding Standard Compliance: Uses camelCase for props, ALL_UPPERCASE for constants, prefixes non-React custom methods with an underscore _ (e.g. _handleUpdateSubmit), uses 4-space indentation, and includes full JSDoc comments.

5. Component Helper Methods (JSDoc Specifications)

async function _fetchTables()
Private Helper Returns: Promise<void>
Fetches list of available system database tables and record counts from /api/admin/edit-database/tables/.
async function _fetchRecords(tableName)
Private Helper @param {string} tableName
Fetches all records for the specified system table from /api/admin/edit-database/records/?table={tableName}.
function _showAlert(msg, type = 'success')
Private Helper
@param {string} msg Alert message string
@param {string} type 'success' or 'error'
Displays top notification banner and sets automatic 4-second dismiss timer.
function _handleSelectRecord(item)
Private Helper @param {Object} item
Selects target record, pre-fills editable field inputs, and opens the edit modal form.
function _handleFieldChange(key, value)
Private Helper @param {string} key @param {string} value
Updates dynamic field value state as the administrator types in the edit modal.
async function _handleUpdateSubmit(e)
Private Helper @param {FormEvent} e
Validates mandatory field presence, submits updated values via PUT API request, and displays success/error notification banners matching the Use-Case specification.

6. Use-Case Rules & Exceptions Matrix

Administrator Use Case Exception Handling

  • ⚠️ Mandatory Field Check: Leaving required fields empty triggers: "Field '{key}' cannot be empty. Please complete all mandatory fields."
  • 🔍 Record Not Found: If the selected record no longer exists, the system displays an error prompt and automatically refreshes the table records.
  • 🔒 System Constraint / Unique Duplicate: Violating unique constraints (e.g. duplicate username or email) displays: "Updated information violates system constraints (such as duplicate unique values). Please provide valid unique information."
  • ⚡ Connection / Server Error: Connection failure displays: "Server or database connection fails. Please try again."
