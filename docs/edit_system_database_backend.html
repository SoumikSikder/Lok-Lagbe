Module: admin.edit_system_database

The admin.edit_system_database package provides backend API endpoints for System Administrators to inspect system database tables, view records, inspect record details, and dynamically update record fields with full constraint and exception validation.

Strict PEP 8 & Sphinx Standard Compliance
This module strictly enforces Python PEP 8 style guidelines (4-space indentation, max 88-char code line limit, max 79-char docstrings line limit, snake_case for functions/variables/methods, PascalCase for classes, first parameter request for view functions) and full Sphinx docstrings.

1. List System Tables: list_system_tables(request)

GET /api/admin/edit-database/tables/
API view to list available system database tables and record counts.

:parameter request: Django HTTP request object
:return: Response containing table metadata and record counts

2. List Table Records: list_table_records(request)

GET /api/admin/edit-database/records/?table={table_name}
API view to list all database records for a selected table.

:parameter request: Django HTTP request object containing 'table' query param
:return: Response containing list of record dictionaries

3. Get Record Detail: get_record_detail(request)

GET /api/admin/edit-database/record/detail/?table={table_name}&id={record_id}
API view to retrieve detailed current information of a selected record.

:parameter request: Django HTTP request object with 'table' and 'id' params
:return: Response containing record field values or 404 error

4. Update System Record: update_system_record(request)

PUT /api/admin/edit-database/record/update/
API view to update a selected database record with validation.

:parameter request: Django HTTP request object with record payload
:return: Response indicating update status

4. URL Routing Configuration — urls.py

File Location: backend/admin/edit_system_database/urls.py

from django.urls import path
from .views import (
    list_system_tables,
    list_table_records,
    get_record_detail,
    update_system_record,
)

urlpatterns = [
    path('tables/', list_system_tables, name='edit_db_tables'),
    path('records/', list_table_records, name='edit_db_records'),
    path('record/detail/', get_record_detail, name='edit_db_record_detail'),
    path('record/update/', update_system_record, name='edit_db_record_update'),
]
