Sphinx Documentation — Backend Module

Module: admin.manage_labour_listing | Project: Lok-Lagbe

1. Module Overview

The admin.manage_labour_listing Django application provides complete RESTful backend endpoints for System Administrators to view, create, edit, and delete labor profiles in the Lok-Lagbe database.

Coding Standards Enforced: Uses PEP 8 naming conventions (snake_case for fields/methods, PascalCase for models), 4-space indentation, line length limits (<88 code, <79 docstrings), and Sphinx docstrings.

2. Model Specification — LaborListing

File Location: backend/admin/manage_labour_listing/models.py

Field Name Type Options / Default Description
name CharField(100) Required Full name of the laborer.
email EmailField Unique, Required Laborer email address (locked after creation).
category CharField(50) CATEGORY_CHOICES Profession (Electrician, Plumber, Painter, Mason, etc.)
skills TextField Default: '' Detailed list or description of laborer skills.
availability CharField(20) Default: 'Full Time' Availability status ('Full Time', 'Part Time', etc.)
status CharField(20) Default: 'Active' Listing status ('Active', 'Pending', 'Inactive').
phone CharField(15) Required Contact telephone number.
profile_image ImageField upload_to='labor_images/' Optional profile photo (.jpg, .jpeg, .png, .webp).

3. Validation & Exception Specification — LaborListingSerializer

File Location: backend/admin/manage_labour_listing/serializers.py

Validation Rules:

  • Mandatory Fields: name, email, category, and phone cannot be blank.
  • Profile Image Format: Rejects files that do not match allowed extensions: .jpg, .jpeg, .png, .webp.
  • Locked Email Rule: During profile update (PUT/PATCH), modifying the email field triggers a validation error:
    "The email field is locked and cannot be edited after registration."

4. API Endpoints — LaborListingViewSet

Base Path: /api/admin/labour-listings/

HTTP Method Endpoint Action Success Status
GET /api/admin/labour-listings/ Retrieve list of all labor listings 200 OK
POST /api/admin/labour-listings/ Create a new labor listing profile 201 Created
PUT /api/admin/labour-listings/{id}/ Update an existing labor listing (Email Locked) 200 OK
DELETE /api/admin/labour-listings/{id}/ Delete a labor listing profile 200 OK
