Module: admin.manage_labour_listing

The admin.manage_labour_listing package contains the entire backend implementation for System Administrators to manage worker profiles in the Lok-Lagbe platform. It provides complete RESTful CRUD operations (Create, Read, Update, Delete), strict input validation, image extension verification, email edit lock enforcement, and standardized JSON responses.

Strict PEP 8 & Sphinx Standard Compliance
This module strictly enforces Python PEP 8 style guidelines (4-space indentation, max 88-char code line limit, max 79-char docstrings line limit, snake_case for functions/variables/methods, PascalCase for classes, ALL_UPPERCASE for constants) and full Sphinx docstring formats.

class LaborListing(models.Model)
Docstring:
Model representing a labor listing profile in the system.
Stores contact information, skill sets, availability status, and profile pictures of registered laborers.

Model Attributes & Field Definitions

Field Name Django Field Type Database Type Constraints / Choices Description
id BigAutoField INTEGER Primary Key, Auto-increment Unique database identifier.
name CharField VARCHAR(100) max_length=100, blank=False Full legal name of the laborer.
email EmailField VARCHAR(254) unique=True, blank=False Email address. Locked upon registration.
category CharField VARCHAR(50) choices=CATEGORY_CHOICES Laborer profession category.
skills TextField TEXT blank=True, default='' Detailed list or description of worker skills.
availability CharField VARCHAR(20) choices=AVAILABILITY_CHOICES, default='Full Time' Current work availability schedule.
status CharField VARCHAR(20) choices=STATUS_CHOICES, default='Active' Profile status ('Active', 'Pending', 'Inactive').
phone CharField VARCHAR(15) max_length=15, blank=False Primary telephone contact number.
profile_image ImageField VARCHAR(100) upload_to='labor_images/', null=True, blank=True Optional profile photo file.
created_at DateTimeField DATETIME auto_now_add=True Timestamp when profile was created.
updated_at DateTimeField DATETIME auto_now=True Timestamp when profile was last modified.

Method: update(self, instance, validated_data) [Email Lock Rule]

def update(self, instance, validated_data)
Updates an existing LaborListing instance. Enforces the exception rule that email cannot be edited after creation.

:parameter instance: Existing LaborListing database object
:parameter validated_data: Dictionary of validated field values
:return: Updated LaborListing instance
:raises serializers.ValidationError: If new_email != instance.email
Exception Rule Enforcement
If an administrator attempts to send a modified email address in a PUT or PATCH request, the serializer immediately halts execution and raises a ValidationError:
{"email": "The email field is locked and cannot be edited."}
