Component: ManageLabourListings

The ManageLabourListings React component provides the complete user interface for System Administrators to view, search, create, update, and remove labor listing profiles. It connects directly to the Django REST API backend endpoints.

Coding Standard Compliance: Uses camelCase for props, ALL_UPPERCASE for constants, prefixes non-React custom methods with an underscore _ (e.g. _handleSubmit), uses 4-space indentation, and includes full JSDoc comments.

5. Component Helper Methods (JSDoc Specifications)

async function _fetchListings()
Private Helper Returns: Promise<void>
Fetches all labor listings from the backend API. Updates listings state or displays an error alert banner if the database request fails.
function _showAlert(message, type = 'success')
Private Helper
@param {string} message Notification banner text
@param {string} type 'success' or 'error'
Displays top notification banner and sets an automatic 5-second dismiss timer.
function _handleFileChange(event)
Private Helper
@param {Event} event File input change event
Validates the file extension against ALLOWED_IMAGE_EXTENSIONS (.jpg, .jpeg, .png, .webp). Rejects unsupported files with an alert banner.
function _validateForm()
Private Helper Returns: boolean
Validates that mandatory fields (name, email, category, phone) are not blank. Returns false and triggers error banner if mandatory fields are missing.
async function _handleSubmit(event)
Private Helper @param {FormEvent} event
Constructs FormData multipart payload and invokes POST (Create) or PUT (Update) API request. In Update mode, the email input field is rendered with disabled={true} to enforce the locked email requirement. Preserves form data on failure so administrator can retry without re-typing.
async function _handleDelete(id)
Private Helper @param {number} id
Prompts a window confirmation modal. Upon confirmation, sends DELETE API request to remove the profile.

6. Use-Case Rules & Exception Handling

System Administrator Rules & Exceptions Matrix

  • 🔒 Locked Email Rule: When editing an existing labor listing (isEditMode = true), the email input is disabled (disabled={true}) with lock indicator 🔒. The email field cannot be modified after initial registration.
  • 🖼️ Image Format Rejection: Uploading non-image formats (e.g. .pdf, .txt, .docx) triggers an error alert: "Unsupported profile image format. Please upload a JPG, JPEG, PNG, or WEBP image."
  • ⚠️ Mandatory Field Checks: Submitting with blank required fields triggers: "Please complete all mandatory fields."
  • 💾 Error Form Preservation: If a database or server connection error occurs, the form remains open and entered data is preserved so the administrator can retry without losing their work.
