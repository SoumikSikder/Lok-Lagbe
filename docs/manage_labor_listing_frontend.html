Component: ManageLabourListings.jsx | Project: Lok-Lagbe

1. Component Overview

The ManageLabourListings component renders the System Administrator interface for managing labor profiles. It connects to the Django backend REST API to perform live CRUD operations, enforces input validation, profile image checking, and locked email editing.

Coding Standards Enforced: Uses camelCase for props, ALL_UPPERCASE for constants, prefixes non-React custom methods with _, 4-space indentation, and full JSDoc comments.

3. Method Documentation (JSDoc Spec)

_fetchListings()

Private Method Returns: Promise<void>

Fetches all labor listings from backend API endpoint /api/admin/labour-listings/.

_handleFileChange(event)

@param {Event} event

Handles profile photo selection. Validates that file extension is one of .jpg, .jpeg, .png, or .webp. Rejects unsupported formats with an alert message.

_validateForm()

Returns: boolean

Checks that mandatory fields (name, email, category, phone) are not empty. Triggers error alert if blank.

_handleSubmit(event)

@param {Event} event

Submits multipart form data to API. On update mode, email input field is disabled/locked to enforce the exception rule.

_handleDelete(id)

@param {number} id

Prompts user confirmation dialog and deletes the target labor profile.

4. Use Case Specifications & Exceptions

Exception Scenarios Handled:
  • Empty Mandatory Fields: Prompts "Please complete all mandatory fields." and prevents submit.
  • Locked Email Field: In Edit mode, email input is rendered as disabled={true} with lock indicator 🔒.
  • Unsupported Image Format: Rejects non-image uploads with message "Unsupported profile image format. Please upload a JPG, JPEG, PNG, or WEBP image."
  • Server / DB Error: Preserves user entered data in form state so changes are not lost upon retry.
