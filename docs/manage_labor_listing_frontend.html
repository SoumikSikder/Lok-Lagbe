Component: ManageLabourListings (Simplified UI)

The ManageLabourListings React component provides a clean, simple, lightweight user interface under 250 lines for System Administrators to view, search, create, update, and remove labor listing profiles. It connects directly to the Django REST API backend endpoints.

Coding Standard Compliance: Uses camelCase for props, ALL_UPPERCASE for constants, prefixes non-React custom methods with an underscore _ (e.g. _handleSubmit), uses 4-space indentation, and includes full JSDoc comments.

5. Component Helper Methods (JSDoc Specifications)

async function _fetchListings()
Private Helper Returns: Promise<void>
Fetches all labor listings from backend API endpoint /api/admin/labour-listings/.
function _showAlert(msg, type = 'success')
Private Helper
@param {string} msg Alert text
@param {string} type 'success' or 'error'
Displays top notification banner with an automatic 4-second dismiss timer.
function _handleInputChange(e)
Private Helper @param {Event} e
Updates controlled form state for input fields, selects, and textareas.
function _handleFileChange(e)
Private Helper @param {Event} e
Validates selected image file extension against ALLOWED_EXTENSIONS (.jpg, .jpeg, .png, .webp). Rejects invalid formats.
function _validateForm()
Private Helper Returns: boolean
Validates that mandatory fields (name, email, phone) are not blank.
async function _handleSubmit(e)
Private Helper @param {FormEvent} e
Submits multipart form data to API using POST (Create) or PUT (Update). In Edit mode, email input is disabled (disabled={true}) to enforce the locked email rule. Preserves form data on failure for retry.
async function _handleDelete(id)
Private Helper @param {number} id
Prompts standard window confirmation dialog and sends DELETE API request.

6. Use-Case Rules & Exceptions

Use Case Exception Rules Matrix

  • 🔒 Locked Email Rule: In Edit mode (isEditMode = true), the email input field is disabled (disabled={true}) with a red (Locked 🔒) label. Email cannot be edited after registration.
  • 🖼️ Image Format Check: Rejects non-supported formats with error message: "Unsupported format! Upload JPG, JPEG, PNG, or WEBP."
  • ⚠️ Mandatory Field Checks: Submitting empty mandatory fields triggers: "Please complete all mandatory fields."
  • 💾 Data Preservation: Server errors keep form state preserved so administrator can retry easily.
