main.jsx

Browser entry point for the React presentation client.

The Django backend follows MVT and returns JSON through DRF Views. This file mounts the separate React interface that presents those JSON responses; it is not a Django HTML template.

utils/auth.js

Access token storage helpers.

The JWT returned by /api/users/login/ is kept in localStorage so it survives a page reload. apiClient.js reads it through getToken() and attaches it as a Bearer header on every request.
