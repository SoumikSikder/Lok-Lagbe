# LokLagbe Backend

## Overview

The LokLagbe backend is a REST API-based backend system developed using Django and Django REST Framework.

It provides authentication, user profile management, and API services for the LokLagbe application.

The backend handles communication between the frontend application and the database.

---

# Technology Stack

| Technology | Purpose |
|------------|---------|
| Python | Programming language |
| Django | Backend framework |
| Django REST Framework | API development |
| JWT Authentication | Secure authentication |
| SQLite | Database |
| Pytest | Backend testing |

---

# Features

## Authentication

- User login system
- JWT token generation
- Secure API authentication
- Protected endpoints


## Profile Management

Users can:

- View profile information
- Update phone number
- Update address
- Update avatar


## API Services

The backend provides REST APIs for frontend communication.
